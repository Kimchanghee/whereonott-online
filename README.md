## 데이터 소스

- **TMDB API** (무료 공식): 영화·TV·배우 메타데이터, 4K 이미지
- **JustWatch 공개 데이터**: OTT 가용성 (한국·미국·일본)
- **공개일정**: 한국 OTT(넷플릭스/티빙/웨이브/쿠팡플레이/디즈니+/왓챠) 신작 일정 RSS·스크래핑

## 자동화 흐름

1. 일 1회 TMDB에서 신규/업데이트 작품 동기화
2. JustWatch에서 OTT 가용성 매칭
3. SSG 빌드 → CloudFront 무효화
