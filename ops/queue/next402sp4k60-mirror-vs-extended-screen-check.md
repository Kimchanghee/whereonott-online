TV와 프로젝터를 함께 쓰려고 HDMI 단자를 늘렸는데 같은 화면만 나온다면, 먼저 장치의 역할부터 확인해야 해요. NEXT-402SP4K60은 한 입력을 두 출력으로 나누는 제품이지, 영상 두 개를 따로 만들어 주는 장치는 아니에요.

이 글은 넥스트유 공식 정보와 판매 모델 자료를 대조하고, 복제와 확장을 설명한 원문을 함께 읽어 정리했어요. 실제 연결 시험이나 특정 스트리밍 서비스의 재생 성공을 확인한 결과는 아니에요.

## 같은 영상을 두 화면에 띄우려는 건가요?
같은 소스의 영상을 TV와 다른 화면에 함께 보내려는 경우에 이 분배기 방향이 맞아요. 연결 그림을 그릴 때 입력 기기는 하나, 출력 화면은 둘로 적어 보세요. 양쪽 화면에서 서로 다른 영화를 고르려는 목적이라면 입력을 복제하는 제품으로 해결되지 않아요.

<figure class="fig"><img src="/images/picks/next402sp4k60-mirror-vs-extended-screen-check/02-sp2.webp" alt="HDMI 단자 세 개와 전원 단자가 보이는 분배기 전체" width="1280" height="853" loading="lazy" decoding="async"><figcaption>HDMI 단자 세 개와 전원 단자가 보이는 분배기 전체</figcaption></figure>

노트북 화면을 넓혀 한쪽에는 문서, 다른 쪽에는 별도 창을 두는 확장 작업도 구분해야 해요. 모니터 개수와 독립 신호 개수는 같은 말이 아니에요. 화면을 더 산 뒤 단자만 추가하면 해결된다고 가정하지 말고, 컴퓨터의 영상 출력 지원부터 살펴보세요.

## 선택기와 분배기는 무엇이 반대인가요?
분배기는 하나의 입력을 여러 출력으로 나누고, 선택기는 여러 입력 중 쓸 것을 고르는 방향이에요. 상품 이름에 비슷한 낱말이 섞여 있어도 단자 방향과 동시 출력 여부를 따로 읽어야 해요. 이 모델의 기준은 HDMI 입력 하나와 출력 둘이에요.

양방향으로 연결된다는 문구만 보고 두 화면이 동시에 켜진다고 판단하지 마세요. 필요한 것은 꽂을 수 있는 방향뿐 아니라 동시에 같은 신호를 보낼 수 있는지예요. 기존 장비의 이름을 적어 입출력 수를 비교하면 방향을 잘못 고르는 일을 줄일 수 있어요.

## 4K 표기만 같으면 두 화면이 다 맞을까요?
아니요. 분배기 본체의 규격 외에 소스 출력, 두 화면의 입력 지원, 각각의 케이블까지 함께 확인해야 해요. 한쪽 화면의 표시 성능을 다른 쪽에도 그대로 기대하지 말고, 실제 사용할 해상도와 주사율을 기기별 안내에서 맞춰 보세요.

공식 상품에는 EDID 딥스위치도 명시돼 있지만, 이 글에서 확인하지 않은 스위치 조합을 임의로 안내하지는 않아요. 정확한 모델의 설명서와 연결된 화면 조건에 맞춰야 해요. 콘텐츠 보호 기능이 필요한 서비스도 장비 전체의 지원 조건을 따로 봐야 하며, 버전 표기 하나로 재생을 보장할 수는 없어요.

## TV 뒤에 선과 전원을 둘 자리가 있나요?
이 제품은 신호선 자리와 별도로 전원 입력 자리를 살펴야 해요. 공식 사진에는 둥근 DC 전원 단자가 있고, 쿠팡 필수 정보에는 DC 5V가 표기돼 있어요. 다른 기기에 쓰던 어댑터를 외형만 보고 대신 연결하지 말고, 제공 구성과 설명서의 조건을 확인하세요.

<figure class="fig"><img src="/images/picks/next402sp4k60-mirror-vs-extended-screen-check/05-sp5.webp" alt="손으로 받쳐 든 검은 금속 분배기" width="1280" height="853" loading="lazy" decoding="async"><figcaption>손으로 받쳐 든 검은 금속 분배기</figcaption></figure>

소스에서 분배기까지 가는 선과 분배기에서 각 화면으로 가는 선을 따로 그려 보세요. 케이블을 꺾어 꽂아야 하는지, 가구 뒤에서 커넥터를 뽑을 수 있는지도 확인할 항목이에요. 배선 길이를 정리할 때는 [HDMI 케이블 길이와 인증 안내](/guides/hdmi-cable-length-certification/)를, 화면 위치를 정할 때는 [거실 배치 안내](/guides/living-room-layout/)를 함께 참고할 수 있어요.

## 어떤 목적이면 다른 구성을 먼저 봐야 할까요?
서로 다른 작업 창, 여러 소스의 독립 배정, 긴 거리 전송이 핵심이라면 단순 분배기부터 고르지 않는 편이 좋아요. 이 글에서는 확인하지 않은 색 신호 형식, 케이블 보장 거리, 지연 수치를 채워 넣지 않았어요. 모델명과 규격이 같아 보여도 판매 구성과 설명서가 다르면 빠진 항목을 먼저 문의하세요.

구매 전에는 원하는 화면 결과를 한 문장으로 적고, 입력과 출력 기기 이름을 나눠 적어 보세요. 그다음 각 연결 구간의 케이블과 전원을 확인하면 돼요. 동일한 영상을 두 장소에 띄우는 목적이며 연결 조건까지 맞는 사람에게 적합한 후보예요.
