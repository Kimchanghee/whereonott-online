TV는 영화를 틀고 옆 모니터는 다른 창을 띄우고 싶은데, HDMI 단자가 하나라 분배기를 찾게 되는 경우가 있어요. 이때 먼저 볼 것은 화면 수가 아니라 두 화면에 무엇을 띄울지예요.

NEXT-602SP4K60의 제조사 상품 정보와 분배기 자료를 바탕으로 연결 목적을 구분합니다. 실제 기기를 연결해 화면이나 지연을 측정한 글은 아니며, 사진의 배치는 연결 전 자리 잡기를 설명하는 장면이에요.

## 분배기를 꽂으면 두 화면을 따로 쓸 수 있나요?
아니요. 이 모델은 HDMI 입력 하나를 출력 두 개로 나누는 1:2 제품이므로, 같은 영상을 두 화면에 함께 보내려는 쪽에 맞아요. 화면마다 다른 창을 놓는 컴퓨터의 확장 출력과는 출발점이 다릅니다.
<figure class="fig"><img src="/images/picks/next602sp4k60-duplicate-vs-extended-display-check/wo-output.webp" alt="검은 분배기 한쪽에 나란히 있는 HDMI 출력 단자 두 개" width="1280" height="853" loading="lazy" decoding="async"><figcaption>검은 분배기 한쪽에 나란히 있는 HDMI 출력 단자 두 개</figcaption></figure>
노트북의 영상 출력 하나를 갈라 놓았다고 영상 소스가 두 개 생기지는 않아요. 발표 화면을 청중용 TV와 작은 확인용 모니터에 같이 보여 주려면 목적이 맞지만, 문서와 영화를 서로 다른 화면에 두려면 컴퓨터의 독립 출력 구성을 확인해야 해요.

선택기도 구분하세요. 입력 여러 개 중 하나를 골라 TV 하나에 보내는 선택기는 반대 방향의 장치예요. 상품 이름에 분배기와 선택기가 함께 적혀 있어도 실제 입력·출력 수와 동시 출력 설명을 기준으로 고르는 편이 분명합니다.

## TV와 모니터 해상도가 다르면 무엇을 물어봐야 하나요?
두 화면을 섞을 계획이면 사용할 출력 해상도와 각 화면이 받는 신호를 먼저 정해야 해요. 4K TV 옆에 낮은 해상도 모니터를 둔다면, 두 출력을 각각 원하는 해상도로 바꿔 주는 기능이 필요한지 판매처에 질문하세요.

이 글에서는 출력별 독립 스케일링이나 EDID 선택 동작을 확인하지 못했으므로 된다고 적지 않았어요. 4K 60Hz라는 짧은 상품명으로 서로 다른 화면 조건까지 해결된다고 생각하지 않는 것이 핵심입니다.

스트리밍 영상을 보낼 목적이라면 소스와 화면의 보호 규격도 함께 대조하세요. 분배기 한 부품만의 HDCP 표기가 연결 전체의 재생 성공을 보장하지는 않아요. 현재 쓰는 장치의 모델명과 화면 두 대의 입력 규격을 적어 두면 질문을 구체적으로 할 수 있습니다.

## 케이블과 전원 자리는 어떻게 준비하나요?
입력면과 출력면을 나누어 보고, 소스에서 들어오는 선 하나와 두 화면으로 나가는 선을 구분해 자리를 잡으세요. 제조사 제품 사진에는 HDMI 입력 옆의 작은 전원 단자가 따로 보이므로, 영상선만 생각하고 전원 경로를 빼놓지 않는 편이 좋습니다.

케이블은 TV장 직선거리보다 실제 돌아가는 경로를 기준으로 준비하세요. 단자 뒤의 굽힘과 가구를 옮길 여유가 필요하지만, 특정 길이까지 문제없다고 이 글에서 시험한 것은 아니에요. 긴 구간의 허용 조건은 모델 설명과 케이블 규격을 함께 확인해야 합니다.

## 어떤 사람에게 맞고, 주문 전 무엇을 확인하나요?
같은 HDMI 영상을 화면 두 대에 나누려는 사람에게 검토할 만한 구성입니다. 반대로 컴퓨터 작업 창을 두 개의 독립 화면으로 늘리는 것이 목적이거나, 화면마다 다른 입력을 동시에 보여 줄 장치가 필요하다면 먼저 다른 출력 구성을 확인하세요.
주문 화면에서는 NEXT-602SP4K60, 혼합 색상, 수량 1개를 맞추세요. 비슷한 이름의 다른 포트 수나 케이블형 제품을 같은 것으로 바꾸지 말고, 전원 구성과 필요한 선이 포함되는지도 현재 판매 설명에서 확인해야 합니다.

남은 질문은 세 가지예요. 두 화면이 받을 공통 신호는 무엇인지, 출력마다 신호 변환이 필요한지, 케이블과 전원을 실제 어디로 보낼 것인지입니다. 이 세 가지가 정리되면 단자 수만 보고 주문하는 것보다 필요한 제품에 가깝게 고를 수 있어요.
